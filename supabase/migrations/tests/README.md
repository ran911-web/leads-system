# בדיקות אוטומטיות

הבדיקות מריצות את הקוד האמיתי של `index.html` בדפדפן headless, כאשר **כל** התעבורה
ל-Supabase נחסמת ומוחזרת ממוק ברמת הרשת. **אין שום קריאה לייצור ואין שינוי בנתוני אמת.**

## הרצה

```bash
npm test                 # בדיקות התנהגות מלאות (Playwright)
npm run test:syntax      # תחביר ומבנה בלבד (Node, מיידי, ללא רשת)
```

התקנה חד-פעמית לפני ההרצה הראשונה של `npm test`:

```bash
npm run test:setup
# שקול ל:
#   pip install playwright
#   python3 -m playwright install chromium
```

`npm run test:syntax` עובד מיד, בלי התקנות.

אפשר גם להריץ על קובץ אחר:

```bash
python3 run_tests.py path/to/index.html
node    check_syntax.js path/to/index.html
```

## הקבצים

| קובץ | מה נבדק |
|---|---|
| `run_tests.py` | 64 בדיקות התנהגות: ייבוא, כפילויות, Excel, תור כתיבות, RPC, סנכרון, תאריכים, רגרסיה, ממשק |
| `check_syntax.js` | 8 בדיקות מבנה: תחביר JS, איזון סוגריים, מזהי HTML כפולים, פונקציות כפולות, איזון div, היעדר סודות |

## מה מכוסה

**הזנת כתובות במסה** — נשמרים רק מזהי הלידים החדשים · דילוג מלא אינו מפעיל שמירה ·
ליד קיים אינו נשלח מחדש · קלט ריק אינו מקצה מזהה.

**חלון הכפילויות** — אי אפשר לסיים כשקיימת כפילות שלא הוכרעה · הכפתור נפתח רק אחרי
כל ההחלטות · ביטול מבטל את הייבוא כולו · הקצאת מזהים תואמת להחלטות.

**ייבוא Excel** — נבנה קובץ xlsx אמיתי ומוזן למערכת. תא ריק בשורה מאוחרת אינו מוחק
ערך קודם · `"לא"` מפורש מחליף `"כן"` · שתי שורות זהות יוצרות ליד אחד.

**תור כתיבות ו-RPC** — שמירת איש קשר ממתינה לסיום שמירת ליד פעילה (נבדק סדר הבקשות
בפועל) · כשל שמירת ליד מונע הפעלת RPC · כשל RPC אינו משנה מידע מקומי · לחיצה כפולה
מפעילה פעולה אחת · אין אובדן מזהים מתור השמירה · מבנה תשובת ה-RPC נקרא נכון ל-`_leadTs`.

**סנכרון אוטומטי** — אין סנכרון כשמנותק (גם אפס בקשות רשת) · טיימר יחיד אחרי כניסה ·
נעצר ומתנקה בהתנתקות · מחזורי כניסה/יציאה אינם מדליפים טיימרים.

**תאריכים** — `2026-02-28`, `2024-02-29` תקינים · `2026-02-29`, `2026-02-31`,
`2026-04-31`, `2026-13-01` נדחים.

**ממשק** — הדאשבורד, הניתוח, אנשי הקשר והדוח החודשי נטענים · אין `NaN`/`undefined` ·
אין תאים שבורים · אין מזהי HTML כפולים · אין שגיאות JavaScript.

## אימות שהבדיקות באמת תופסות תקלות

הבדיקות בוחנות התנהגות (סדר בקשות רשת, מצב זיכרון, `localStorage`), לא מחרוזות בקוד.
לאימות: שוברים במכוון את תור הכתיבות ואת אימות התאריך —

   ❌ 6. fmtDate(2026-02-31)
   ❌ 6. fmtDate(2026-13-01)
